# 飞送即时零售 建设方案

> 30分钟 · 万物到家

飞系电商系列成员 · 零依赖（Python 标准库 + SQLite）· 端口 8106

## 一、系统简介

即时零售（O2O）：线上下单、门店3公里履约、骑手调度。2025 年即时零售 1.19 万亿（+48.25%），全网增速第一；医药单超半数 30 分钟送达。核心资产是 LBS 定位、门店实时库存、骑手运力调度三件事。

## 二、功能域

| 模块 | 说明 |
| --- | --- |
| 门店 | 门店名、位置、配送半径(km)、状态 |
| 商品 | 商品名、价格(元)、库存、分类、描述 |
| 门店库存 | 门店ID、商品ID、实时库存、水位 |
| 骑手 | 骑手、电话、状态、评分 |
| 配送单 | 配送单号、订单ID、门店ID、骑手、状态、时效 |
| 购物车 | 用户、商品ID、数量 |
| 订单 | 订单号、下单人、商品明细、金额(元)、收货地址、状态 |
| 用户 | 用户名、密码、角色 |

## 三、角色与权限

- 门店：维护门店库存、拣货出单
- 骑手：接单、取货、送达确认
- 消费者：按距离选门店、下单、实时跟踪配送

## 四、核心业务流程

1. 消费者选门店下单 → 订单推送到门店 → 门店拣货 → 骑手抢单/派单 → 取货配送 → 送达确认
2. 库存并发：门店库存实时扣减，超卖即熔断

## 五、数据模型

| 表名 | 中文名 | 字段 |

## 六、技术架构

- **后端**：`backend/engine.py` 通用引擎（Python `http.server` + `sqlite3`，零第三方依赖），业务差异全部收敛到 `spec.json` 规格文件——表结构、字段、种子数据由规格驱动，引擎按规格建库、建表、灌种子、暴露 REST。
- **前端**：`frontend/` 原生 JS 单页应用（SPA），同样规格驱动：门店视图（商品卡片/搜索/购物车/结算）、统计视图、后台视图（各表 CRUD，自动生成导航/表格/表单）。
- **接口风格**：REST + JSON，登录态用内存 Token（Bearer）。
- **品牌**：飞送（#ea580c → #f59e0b 渐变，Logo 字符「速」——「速」即时效——即时零售的产品就是履约本身）。

## 七、API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/health | 健康检查（无鉴权，运维探活用） |
| POST | /api/login | 登录，返回 Token 与角色 |
| GET | /api/dashboard | 登录后看板：各表行数、今日订单数与 GMV、低库存预警 |
| GET | /api/spec | 系统规格（品牌 + 全部表结构） |
| GET | /api/stats | 各表行数统计（驾驶舱） |
| GET | /api/<table> | 列表查询，支持 `?q=` 关键词 |
| GET | /api/<table>/<id> | 详情 |
| POST | /api/<table> | 新增（ops 及以上） |
| PUT | /api/<table>/<id> | 更新（ops 及以上） |
| DELETE | /api/<table>/<id> | 删除（仅 admin） |
| POST | /api/cart | 加入购物车（含商品校验与同品合并） |
| GET | /api/cart | 我的购物车 |
| POST | /api/checkout | 结算下单：生成订单、扣库存、清购物车 |
| POST | /api/orders/<id>/pay | 订单支付：待支付 → 已支付 |
| GET | /api/orders | 我的订单 |

**三角色权限**（家族规范，密码 sha256+盐 哈希落库）：

| 角色 | 账号 | 权限 |
| --- | --- | --- |
| admin | admin / admin123 | 全权（含删除） |
| ops | ops01 / ops123456 | 读写业务数据，不可删除 |
| viewer | view01 / view123456 | 只读 |

## 八、部署运行

```bash
cd backend
FEI_PORT=8106 python server.py
# 或直接
python server.py   # 读取 spec.json 中的端口 8106
```

浏览器访问 `http://127.0.0.1:8106/`，三角色账号见上方权限表。

## 九、测试与巡检

```bash
python -m pytest tests/ -q        # API 集成测试
python tools/ui_check.py          # UI 巡检：API 探活 + 门店页无头截图（tools/shots/home.png）
```

集成测试真实起服务，断言：健康检查 → 规格读取 → 登录鉴权（未登录写 401）→ 三角色权限（viewer 写 403 / ops 删 403 / admin 全权）→ 密码哈希登录 → 业务表 CRUD → 加购 → 结算 → 支付 → 库存扣减 → 我的订单 → 看板。
